# EXE / PE / 二进制逆向（0 条，2026-11-10 新建，等每日采集补）
> 条目为公开资料整理（出处见文末「参考」），`利用步骤` 属待验证假设；出报告前按目标版本自验并把 `verified` 置为 true。

收录范围：Windows / Linux 可执行文件漏洞（有 CVE 或无 CVE 都收），以及逆向新知识：新工具、新反混淆/脱壳手法、新漏洞挖掘方法。
每条必须写清：程序名 + 版本 + 文件哈希（有就写）+ 证据（反汇编片段 / 调试器截图描述 / PoC 代码），只凭“某 EXE 有漏洞”一句话不收。

## 存储边界（2026-11-10 用户定）
- 只记：程序名、版本、文件哈希、证据位置（反汇编片段所在函数/偏移）、来源链接。
- 不要提交：原始 EXE/PE 样本、完整反编译/反汇编输出、敏感数据（密钥、Token、个人数据、凭证）。
- 条目类型：`entry_type=vuln`（已确认漏洞卡）与 `entry_type=method`（逆向方法/工具卡）分开，方法卡不要写成已确认漏洞。
